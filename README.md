## 如何打开（电脑）

**首选**：直接访问永久链接 <https://yuuuiu.github.io/chenjinyu-portfolio/>（推荐投递用）

**本地预览**（离线编辑时）：双击 `打开作品集.bat` → 自动启动本地服务器并打开浏览器：
<http://127.0.0.1:8321/>

**命令行**：在「作品集」文件夹下执行：

```powershell
python server.py
```

> 建议用 server.py（或 bat）而不是直接双击 index.html：本地服务器支持
> HTTP Range 分段响应，视频**拖动进度条、快进快退**更流畅。

## 如何在手机上通过局域网访问

1. 手机与电脑连接**同一个 Wi-Fi**；电脑上双击 `打开作品集.bat`
2. 查询电脑局域网 IP：命令行输入 `ipconfig`，找「无线局域网适配器 WLAN → IPv4 地址」，例如 `192.168.1.5`
3. 手机浏览器访问：`http://192.168.1.5:8321/`
4. 若打不开：Windows 防火墙弹窗勾选「专用网络允许」，并确认手机电脑同一网络

## 使用说明

- 顶部导航：首页 / 壹·AI影像 / 贰·交互装置 / 叁·三维建模 / 肆·影视创作 / 关于我，点击平滑滚动
- 点击任意作品卡片 → 打开**全屏弹层播放器**（自动播放 + 进度控制 + 可拖动进度条）
- 关闭播放器：点击右上角 × / 按 `ESC` / 点击视频外深色遮罩
- 手机端导航自动折叠为汉堡菜单；视频卡片网格自动变为 2 列 / 1 列

## 技术说明

- 纯原生实现：IntersectionObserver 滚动渐入、导航高亮、CSS 金色粒子背景
- 视频懒加载：封面点击后才加载 `<video>`，首屏无大文件流量
- 已通过 Chromium headless 渲染验证：18 个作品卡片全部渲染、控制台零报错
- 视频全部 faststart（moov 前置），配合 Range 服务器可秒开、可拖动
- 所有路径均为相对路径，UTF-8 编码，可直接拷贝到任意静态托管（GitHub Pages / Nginx 等）
